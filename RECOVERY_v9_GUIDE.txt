DEPLOYMENT
1. Extract ZIP.
2. Replace/add ALL files inside this folder in the ROOT of the existing GitHub repository.
3. Commit and wait for GitHub Pages deployment.
4. DO NOT change Firebase config/project.
5. Firestore rules: no new change is needed if the v6/v8 rules are already published; the included rules are the SAME rules used by v8.
6. Open the site and hard refresh once. The v9 service worker removes old AETHER/NOVA caches automatically.
